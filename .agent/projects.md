## Project: igen-landing-page
- **Description**: Landing page for iGen Tech featuring modern design, GSAP animations, dynamic solutions page, and contact submission forms.
- **Path**: `d:/Igen Tech/ldp`

- **Architecture**:

  - Backend: RESTful Node.js API server (under `backend/`)
- **Status**: Active development.
